# 장면 집필 에이전트 루프

## 입력

- 이번 장면의 관점 인물, 장소, 시간
- 장면 시작 시 인물의 목표와 압박
- 반드시 일어날 변화와 장면 종료 상태
- 공개하면 안 되는 정보, 피할 표현, 분량과 문체
- 직전 장면 요약과 관련 인물·세계관 사실

## 실행 순서

1. **검색**: 입력에 등장한 인물, 장소, 물건, 사건, 문체 규칙을 찾는다. 관련성이 낮은 설정은 문맥에 넣지 않는다.
2. **계획**: `목표 → 방해 → 선택 → 결과`를 한 줄씩 쓴다. 결과는 다음 장면의 조건을 바꿔야 한다.
3. **초안**: 계획을 설명하지 말고 행동, 감각, 대사와 반응으로 장면화한다. 관점 인물이 알 수 없는 사실은 확정적으로 서술하지 않는다.
4. **비평**: 초안에서 가장 큰 문제 세 개만 찾는다. 설정 위반, 인과 단절, 인물 목소리 혼합, 반복 설명, 장면 정체를 우선한다.
5. **제한 수정**: 확정 설정과 사용자의 문장을 보존하면서 지적된 문제만 고친다. 수정 때문에 새 정보가 생기면 그것이 설정 후보인지 일회성 묘사인지 구분한다.

## 통과 조건

- 장면 전후 상태가 실제로 달라진다.
- 주인공의 선택이나 실패가 변화를 만든다.
- 중요한 감정은 이름표보다 원인과 행동으로 보인다.
- 다음 장면이 필요한 질문이나 결과가 남는다.
- 비평 단계가 작품의 취향을 보편 법칙처럼 강요하지 않는다.

에이전트 루프는 모든 문장을 여러 번 다시 쓰는 기능이 아니다. 초안이 이미 요구를 만족하면 불필요한 수정 단계를 생략하고, 사용자가 직접 고친 문장은 가장 높은 우선순위의 의도로 취급한다.

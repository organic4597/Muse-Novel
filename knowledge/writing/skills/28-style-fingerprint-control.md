# 문체 지문 유지 절차

문체 프로필은 “감성적”, “유려함” 같은 말만으로 만들지 않는다. 다음 항목을 작품별 경향으로 기록한다.

- 평균적인 문장 길이와 짧은 문장을 쓰는 순간
- 문단 길이, 대사와 서술의 비율
- 1인칭·3인칭, 시제, 관점 인물과 심리적 거리
- 감정을 직접 이름 붙이는 정도와 행동·감각으로 우회하는 정도
- 비유의 빈도와 주로 사용하는 감각 영역
- 선호 어휘, 인물별 말버릇, 피해야 할 상투 표현
- 장면 전환과 회차 끝을 닫는 방식

## 적용

1. 사용자가 쓴 대표 샘플에서 반복되는 경향을 추출한다.
2. 각 경향에 짧은 근거 예시를 연결한다.
3. 생성 프롬프트에는 현재 장면에 필요한 5~8개 규칙만 넣는다.
4. 생성 후 시점·시제·문장 길이·금지 표현·인물 말투를 검사한다.
5. 이탈한 문장만 고치고 내용까지 전면 재작성하지 않는다.

의도적인 변화는 오류가 아니다. 전투에서 문장이 짧아지거나 특정 인물 시점에서 어휘가 달라지는 것은 장면 목적과 연결되면 허용한다. “일관성”은 모든 회차를 같은 리듬으로 평평하게 만드는 것이 아니라, 변화가 작품의 규칙 안에서 설명되도록 하는 것이다.

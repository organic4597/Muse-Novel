# 외부 소설·자료를 추가하는 기준

현대 소설의 전체 원문을 허가 없이 지식 베이스에 복사하지 않는다. 장르 관습, 플롯 장치와 문체 특징은 직접 분석한 요약으로 기록하고 특정 문장을 생성 결과에 복제하지 않는다.

원문을 저장할 수 있는 자료는 다음처럼 구분한다.

- 사용자가 직접 작성해 사용할 권리가 있는 원고
- 저작권자가 명시적으로 허락한 자료
- 적용 지역에서 공개 도메인임을 확인한 자료
- 라이선스가 허용하는 범위와 표시 조건을 지킨 공개 자료

각 외부 자료에는 제목, 저자·기관, 원본 URL, 접근일, 라이선스, 적용 지역, 원문 저장 여부, 사용 목적을 기록한다. 번역문은 원작과 별도의 저작권이 있을 수 있으므로 따로 확인한다.

공개 도메인 소설을 넣더라도 그대로 프롬프트에 길게 삽입하기보다 장면 단위로 색인하고, 현재 작업과 관련 있는 짧은 부분만 검색한다. 특정 작가의 고유 문체를 모방하라는 지시보다 문장 길이, 시점, 대사 비율, 감각 선택 같은 일반 특성으로 변환한다.

Project Gutenberg는 대다수 자료가 미국에서 공개 도메인이지만, 다른 국가에서는 상태가 다를 수 있고 프로젝트 명칭과 배포 조건도 별도로 확인해야 한다고 안내한다.

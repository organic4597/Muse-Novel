## 판단과 남은 검증

병목은 웹 검색보다 **추론 장비의 GPU 자원 경쟁·VRAM 여유 부족**일 가능성이 높습니다.
Windows의 GPU 메모리 페이지 이동이나 공유 메모리 사용이 영향을 줄 수 있으나,
현재 지표만으로 정확한 메모리 폴백 발생을 확정하지는 않았습니다.

[NVIDIA 공식 설명](https://nvidia.custhelp.com/app/answers/detail/a_id/5490)은 VRAM이 거의 가득 차면
공유 메모리 사용으로 성능이 낮아질 수 있다고 설명합니다. 해당 문서는 일반적인 Windows CUDA
동작 참고이며, 이 WSL 환경의 원인을 단독으로 증명하는 자료는 아닙니다.

추가로 검증할 순서는 다음과 같습니다.

1. 사용자가 GPU 작업을 종료한 상태에서 같은 짧은 추론 요청을 비교합니다. 게임·앱을 임의로 종료하지 않습니다.
2. 현재 102,400 컨텍스트를 실제 집필에 필요한 범위로 줄여 VRAM 여유를 확보하는 비교 실험을 검토합니다.
3. 텍스트 전용 사용 시 멀티모달 projector와 MTP draft가 차지하는 메모리를 함께 검토합니다.
4. 동일 조건에서 입력 처리·생성 속도가 회복되는지 확인한 후에 운영 설정 변경 여부를 결정합니다.

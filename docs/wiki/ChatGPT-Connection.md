# ChatGPT 계정 연결

ChatGPT 구독으로 Codex를 사용할 수 있는 계정을 Muse Novel에 연결하는 선택형 실험 기능입니다. API 키를 발급하지 않으며 사용량은 해당 계정의 Codex 한도를 따릅니다. 계정 연결을 완료하기 전까지 기존 API 제공자를 계속 사용할 수 있습니다.

## 처음 연결하기

1. Muse Novel에 관리자 계정으로 로그인합니다.
2. **AI 환경 → 스토리 구상용 AI → Provider → ChatGPT 계정 연결 (API 키 없음)**을 선택합니다. 작품별 제공자 화면에서는 **ChatGPT 계정** 탭을 사용합니다.
3. **ChatGPT로 로그인**을 누릅니다.
4. **OpenAI 공식 로그인 열기**를 누르고 본인 ChatGPT 계정으로 로그인해 표시된 일회용 코드를 입력합니다. 비밀번호·인증 토큰을 Muse Novel 입력창에 붙여넣지 않습니다.
5. 연결됨 표시가 나오면 계정에서 제공되는 모델을 선택합니다.
6. **공통 기본 AI로 사용** 또는 **이 작품의 기본 AI로 사용**을 누릅니다. 작품별 AI가 있으면 공통 기본값보다 우선합니다.

기기 코드 인증이 차단되어 있다면 ChatGPT 보안 설정 또는 조직 관리자의 설정에서 device code login을 허용해야 합니다. 코드가 만료되었거나 로그인에 실패하면 연결을 해제한 뒤 다시 시작하세요. 로그인 진행 중에 페이지를 다시 열어도 서버가 보관한 진행 상태를 확인할 수 있습니다.

## 호환 범위

- 기존 `createProvider` / AI SDK의 `generateText`, `streamText`, `Output.object` 호출을 변경하지 않고 사용합니다.
- 스토리 구상, 스토리라인 대화, 세계관 자동 구축, 작성 요청, 비평, 일관성 검사 등 기존 텍스트·JSON 흐름에 연결됩니다. 앱 서버의 JSON Schema 출력 기능으로 구조화 응답을 요청합니다.
- 응답 중단·10분 제한·오류 종료를 처리하며, 생성 중 상태 메시지는 최종 본문이나 JSON에 섞지 않습니다. 일부 모델이 최종 메시지 구분 정보를 제공하지 않으면 해당 메시지 완료 시 출력됩니다.
- `temperature`, `topP`, 페널티, seed, `maxOutputTokens` 등 Codex가 직접 노출하지 않는 옵션은 SDK 경고로 알리고 무시합니다. 따라서 모든 API 파라미터가 동일하게 작동하는 범용 HTTP API 대체품은 아닙니다. 앱 자체 분량 프롬프트와 결과 검증은 유지됩니다.
- 종료 문자열은 반환 텍스트에서 처리하고, 과도한 출력에는 별도 안전 한도를 적용합니다. 내부 추론 토큰에 대한 직접 상한을 보장하지는 않습니다.
- 모델 내 임의 함수 실행은 막습니다. 검색·자료 조회·에이전트 반복은 기존 Muse Novel 서버 로직이 수행합니다.
- 이미지 생성·임베딩은 기존 별도 제공자를 사용합니다. Ghost Text의 기존 전용 설정은 변경하지 않습니다. 일반 AI를 상속하도록 설정된 경우에는 동일 어댑터를 이용할 수 있으나 지연·구독 한도 때문에 실시간 자동완성에는 로컬 전용 모델을 권장합니다.

## 서버 설치와 보안

Docker 이미지는 Codex CLI `0.153.4`를 고정 설치합니다. 직접 실행할 때는 `npm install -g @openai/codex@0.153.4`를 실행하거나 `MUSE_CODEX_BIN`에 해당 실행 파일을 지정하세요. 서버에서 OpenAI 인증 및 추론 서비스로 통신할 수 있어야 합니다.

브라우저가 Codex 포트에 직접 접속하지 않습니다. Muse Novel 서버가 자식 프로세스와 표준 입출력 JSON-RPC로 통신하며 외부 WebSocket 포트는 열지 않습니다. 공식 App Server 규격은 실험적이므로 런타임 버전을 올릴 때 회귀 테스트가 필요합니다.

인증은 Muse Novel 인증 디렉토리의 `chatgpt/` 하위에 분리합니다. 일반적으로 `data/auth/chatgpt/`입니다. 기존 데스크톱 Codex의 로그인 파일은 복사하거나 재사용하지 않습니다. API 키와 앱 비밀 환경변수도 자식 프로세스에 전달하지 않습니다. 인증 캐시는 서버 디스크의 민감정보이므로 Git·공개 백업·진단 로그에 포함하지 마세요. 이 경로가 들어 있는 데이터 백업도 비밀번호처럼 보호해야 합니다.

현재 Muse Novel은 서버 단위 관리자 인증 구조이므로 연결은 이 서버의 작품에서 공유됩니다. 서로 신뢰하지 않는 사용자가 사용하는 공개 다중 사용자 서비스에서는 그대로 사용하지 말고 사용자별 인증·프로세스·접근 권한을 먼저 분리해야 합니다.

요청마다 임시 Codex 세션을 만들며 환경 접근, shell, 앱, 플러그인, 브라우저와 이미지 도구를 끕니다. 프로젝트 지침 파일도 읽지 않습니다. 읽기 전용 설정과 도구 요청 거부를 함께 적용합니다. 로그인 완료 후에도 사이트의 원고 승인·저장 절차는 그대로 유지됩니다.

**연결 해제**는 이 서버의 Codex 인증을 지우며 원고나 기존 API 설정은 삭제하지 않습니다. ChatGPT가 기본 제공자인 상태에서 연결을 해제하면 다른 제공자를 직접 기본값으로 선택해야 합니다. 실패·한도 초과 시 유료 API로 자동 전환하지 않습니다.

공식 참고: [인증](https://learn.chatgpt.com/docs/auth), [App Server](https://learn.chatgpt.com/docs/app-server).

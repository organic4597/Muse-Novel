# 로드맵

이 문서는 현재 코드에 없는 기능과 품질 개선이 필요한 기능을 구분합니다. 완료된 기반 기능은 [주요 기능](Features)을 참고하세요.

## 우선순위 1: Ghost Text 고도화

Ghost Text는 현재 미완성입니다.

- 실제 작가 문체·금지 표현·시점·대사 비율 유지
- 지속 상태 메모와 작품 기억 검색 결합
- 직전 문장 복사, 상투 표현, 메타 답변 억제
- 소형/MoE 전용 모델의 OpenAI 호환 API 선택
- 첫 토큰 지연, 전체 지연, 채택률·취소율 측정
- 단어·문장 단위 부분 적용 UX 개선
- 장문 프로젝트 회귀 평가 세트 구축

## 우선순위 2: 이미지와 LoRA

- 캐릭터별 LoRA 프리셋과 적용 여부 검증
- LoRA 학습 요청·진행률·취소·완료 등록 공통 계약
- 캐릭터 외형 일관성을 위한 seed·prompt·모델 이력
- 지형, 도시, 종파, 건물, 던전과 아이템 이미지 생성
- 지도 영역·세계관 설명을 이미지 생성 입력으로 사용
- 결과 승인·거부·재생성과 원본 항목·지도 핀 연결
- image-to-image, inpaint, ControlNet
- fast/balanced/quality 속도 프리셋

## 우선순위 3: 이야기 일관성

- 설정 변경이 영향을 주는 항목을 더 정확히 추적
- 복선 생성·등장·회수 상태의 전용 UI
- 챕터 종료 시 상태 메모 갱신 후보 자동 제안
- 인물별 시간선, 위치와 소지품 충돌 검사
- 확정 설정과 AI 추측의 표시 구분 강화
- 대규모 프로젝트의 의미 검색 평가·재인덱싱 UX

## 우선순위 4: 세계관과 지도

- 핀·카테고리 필터와 레이어
- 거리·경로·세력권·지역 경계 표현
- 지도별 시점 또는 시대 버전
- 핀 대량 가져오기·내보내기
- 500핀 이상에서 공간 인덱스 또는 타일 엔진 검토
- 세계관 자동 구축 후보의 더 정밀한 출처 검증

## 우선순위 5: 제품과 운영

- 한국어/영어 locale 구조
- 계정 복구 또는 안전한 관리자 재설정 절차
- 백업·복원 UI와 무결성 검사
- provider별 성능·오류 진단 화면
- 모바일 집필·지도 UX 개선
- 접근성 키보드 회귀 테스트 확대

## 완료 기준

기능 버튼이 존재하는 것만으로 완료 처리하지 않습니다.

- 정상 흐름과 실패·취소·재시도 테스트
- 긴 입력과 출력 한도에서 데이터 손실 방지
- 현재 구현·제한·운영법 문서화
- 외부 API가 없어도 핵심 원고 데이터 접근 가능
- 사용자 승인 없이 설정이나 원고를 덮어쓰지 않음

# 스토리 구상

홈의 **스토리 구상** 탭에서 AI와 대화하며 작품 기획을 점진적으로 확정하고 실제 프로젝트로 전환합니다.

## 사용 흐름

1. 자유로운 아이디어나 추천 문장으로 대화를 시작합니다.
2. AI가 현재까지 확정된 내용과 다음에 결정할 항목을 분리해 질문합니다.
3. 응답 텍스트는 생성되는 즉시 실시간 스트리밍으로 표시됩니다.
4. 우측 기획 초안에서 제목·장르·시놉시스·인물·세계관·플롯을 확인합니다.
5. 아직 중반까지만 정했다면 완료하지 않고 다음 설정을 계속 대화합니다.
6. 충분히 검토한 뒤 **이 기획으로 소설 목록에 추가**를 눌러 프로젝트를 생성합니다.

프로젝트 생성 뒤에도 작품 정보, 캐릭터, 세계관, 지도에서 각 설정을 수정할 수 있습니다. 기획 완료는 설정을 잠그는 동작이 아닙니다.

## 기획 초안 구조

- title, genre, synopsis, premise
- tone, themes
- characters
- worldEntries
- plot/phase 정보
- firstChapterOutline

AI 응답의 설명과 구조화 draft는 분리됩니다. 표·목록은 GitHub Flavored Markdown으로 렌더링하며 원문 HTML은 실행하지 않습니다.

## 저장 정책

- 구상 중 대화와 초안은 브라우저 localStorage에 임시 저장
- 프로젝트 적용 시에만 DB에 프로젝트·캐릭터·세계관·첫 장 개요 생성
- 원본 기획 snapshot은 프로젝트 설정에 보존
- 브라우저 저장소를 지우거나 다른 브라우저를 사용하면 미적용 구상 세션이 보이지 않을 수 있음

## 스트리밍과 제한 시간

서버는 모델 텍스트 조각을 바로 전달하면서 동시에 최종 구조화 결과를 조립합니다. 입력창은 요청 종료·오류·취소 시 다시 활성화됩니다. 일반 스토리 구상 요청은 대기열 시간을 포함해 최대 10분 제한을 사용합니다.

완료 전에 연결이 끊기거나 출력 한도에 도달하면 잘린 JSON을 확정 draft로 적용하지 않습니다. 다시 요청할 때는 전체 이야기를 처음부터 재생성하기보다 마지막 확정 상태에서 이어가도록 지시하세요.

## 검색과 창작 지식

스토리 구상은 내부 창작 지식과 필요 시 SearXNG 검색 결과를 참고할 수 있습니다. 검색 계획·호출·출처 정리는 Muse Novel 서버가 담당하며 LLM 서버는 추론만 수행합니다. Ghost Text에는 웹 검색을 사용하지 않습니다.

## 모델 응답 처리

Qwen 계열이 출력하는 `<think>...</think>` 추론 블록은 구조화 파싱 전에 제거합니다. 같은 고유명사가 반복되는 문제를 줄이기 위해 현재 draft, 사용자 요청, 최근 대화를 프롬프트에 명시하고 새 설정을 기존 확정 설정과 구분합니다.

## 잘 쓰는 방법

- “아직 1막까지만 정했고 완료가 아니다”처럼 현재 단계 명시
- 시점, 장르 약속, 금지 요소, 결말 방향을 따로 전달
- AI가 임의로 확정한 내용은 즉시 수정 요청
- 큰 세계관 목록은 World assistant 후보 승인 흐름 사용
- 최종 적용 전에 인물 이름과 1장 개요를 한 번 더 확인

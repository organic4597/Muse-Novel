# Ghost Text 자동완성

> 현재 상태: 기본 자동완성 흐름은 작동하지만 품질·응답 속도·장문 일관성을 개선 중인 미완성 기능입니다. 중요한 원고는 제안을 그대로 확정하기 전에 반드시 검토하세요.

## 동작

- 입력 정지 후 짧은 debounce를 거쳐 자동 요청
- 실제 커서의 prefix, suffix와 현재 블록 수집
- 최근 원고, 프로젝트 설정, 문체 프로필과 관련 설정을 제한된 문맥으로 전달
- 자동 호출과 명시적 호출의 생성 길이·temperature 분리
- 클라이언트/서버 캐시와 중복 요청 취소
- 응답 도착 시 커서 문맥이 달라졌으면 결과 폐기
- suffix 반복, 메타 답변, 과도한 반복을 후처리에서 거부

## 키보드

| 키 | 동작 |
| --- | --- |
| `Tab` | 제안 전체 적용 |
| `Alt+→` | 다음 단어만 적용 |
| `Esc` | 제안 숨김 및 요청 취소 |
| `Ctrl+Alt+Space` | 새 제안 명시적 요청 |
| `Alt+R` | 다른 표현으로 재생성 |

`Enter`, 일반 방향키와 `Ctrl+Space`는 Ghost Text가 가로채지 않습니다.

## 현재 한계

- 긴 챕터 전체의 문체를 항상 유지하지 못할 수 있음
- 상태 메모·복선·소지품 같은 원거리 설정을 놓칠 수 있음
- 작은 모델은 상투 표현과 직전 문장 반복이 늘어날 수 있음
- 큰 모델은 첫 토큰 지연이 자동완성 UX에 맞지 않을 수 있음
- `/v1/completions` 지원 수준이 OpenAI 호환 서버마다 다름

현재는 한 문장 또는 짧은 구절 제안에 사용하는 것을 권장합니다. 긴 장면은 [집필 에이전트](Writing-Workspace)를 사용하세요.

## 우선 개선 계획

1. 작가별 문체·금지 표현·대사 비율을 안정적으로 유지
2. 지속 상태 메모와 작품 기억 검색 결합
3. 반복·상투 표현 평가와 후보 재순위화
4. 소형/MoE 자동완성 모델을 별도 API로 선택
5. 첫 토큰·전체 지연 측정과 적응형 길이
6. 실제 채택률과 취소율 기반 품질 평가

## 서버 규격

기본 경로는 OpenAI 호환 `POST /v1/completions`입니다. Ghost Text는 검색이나 에이전트 루프를 실행하지 않으며 짧은 제한 시간 안에 응답하지 못하면 조용히 취소합니다.

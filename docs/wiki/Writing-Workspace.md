# 집필 작업실

프로젝트의 **집필** 탭은 챕터 목록, Plate.js 편집기, 자동 저장, 작가 노트, 지속 상태 메모, 집필 지능 패널을 한 화면에서 연결합니다.

## 챕터와 자동 저장

- 챕터를 만들고 제목·순서를 관리합니다.
- 편집 내용은 서버에 자동 저장됩니다.
- 저장 전에 브라우저가 닫히거나 통신이 끊기면 IndexedDB outbox를 우선 사용하고 제한된 환경에서는 localStorage 복구본을 사용합니다.
- 챕터를 다시 열 때 서버 저장본과 복구본이 다르면 복원 여부를 묻습니다.
- 저장 실패 시 상태 표시와 재시도 버튼을 확인합니다.

자동 저장이 진행 중일 때 탭을 즉시 닫기보다 저장 완료 표시를 확인하는 편이 안전합니다.

## 작가 노트

작품 전체에서 계속 지켜야 하는 짧은 규칙을 기록합니다.

- 반드시 유지할 문체와 시점
- 금지 표현과 피해야 할 전개
- 이번 연재의 핵심 감정 약속
- 다음 장면에서 회수할 복선

작가 노트는 프로젝트 설정에 저장되며 집필 AI의 기준으로 사용됩니다. 장문의 설정 백과는 세계관 항목이나 창작 위키에 두고 작가 노트에는 우선순위가 높은 규칙만 남기는 것이 좋습니다.

## 스토리라인 노트와 AI 대화

왼쪽 **작가 노트** 폴더의 텍스트 노트는 전체 플롯·스토리라인·미확정 설정을 자유롭게 정리하는 공간입니다. 원고와 같은 서식 도구를 사용하며, 상단의 짧은 집필 규칙용 작가 노트와는 별도로 저장됩니다.

1. 텍스트 노트를 열고 **AI와 구상**을 누릅니다.
2. 다음 전개, 인물 동기, 사건 인과, 복선 회수 등을 질문합니다. 필요한 경우 **집중 참조할 회차**를 선택합니다.
3. **전송** 또는 `Ctrl/⌘ + Enter`로 보냅니다. Enter만 누르면 줄바꿈합니다.
4. 답변은 실시간으로 표시됩니다. **참고한 원고 범위**에서 전달된 회차와 발췌 여부를 확인합니다.
5. 마음에 드는 답변은 **핵심 정리해 노트에 추가**로 반영할 수 있습니다. AI가 질문과 답변을 한 번 더 검토해 기존 노트와 겹치는 설명을 빼고, **확정된 내용 / 검토할 제안 / 남은 질문**으로 구분해 노트 끝에 덧붙입니다. 대화 전문과 원고는 자동으로 복사하거나 교체하지 않습니다.
6. 기존 설정을 바꾸거나 지우고 싶다면 대화에서 변경 내용을 요청한 뒤 해당 답변의 **노트 수정안 만들기**를 누릅니다. 현재 내용과 변경 후 내용을 비교하고 **승인하고 반영**해야 실제 노트가 바뀝니다. AI가 원문에서 정확히 찾지 못한 문구, 여러 번 등장해 대상을 특정할 수 없는 문구, 서로 겹치는 변경은 자동 제외됩니다.

일반 AI 제공자 설정을 사용하며 Ghost Text 전용 모델과는 분리됩니다. 별도 LLM 도구 서버는 필요하지 않습니다. 웹 서버가 저장된 원고·세계관·현재 노트와 작법 자료를 모아 기존 API에 전달합니다. 이 대화 자체는 웹 검색을 실행하지 않습니다.

대화는 노트별로 최근 60개 메시지를 서버에 보관합니다. 긴 자료와 대화는 설정된 컨텍스트 크기에 맞춰 일부만 전달하므로, 전체 소설을 매번 정독하는 기능은 아닙니다. 미확정 구상과 AI 제안은 정전으로 자동 확정되지 않습니다. 중요한 결론은 노트에 남겨주세요.

중단·오류 시 질문을 입력창에 복원합니다. 미완료 응답은 대화에 저장하지 않으며, 다른 탭과 충돌하면 **대화 새로고침** 후 다시 요청하세요. **대화 비우기**는 이 노트의 대화만 지우고 노트 본문과 원고는 유지합니다. 노트를 닫으면 진행 중인 요청도 중단됩니다. 최대 요청 시간은 10분입니다.

## 이번 화 등장 항목

원고 위의 작은 표시줄에서 `인물`, `장소·지형`, `물건`, `단체`, `기타`를 드롭다운으로 관리합니다. 항목마다 `직접 등장`과 `언급만`을 구분하고 이번 화에서의 역할·상태 메모를 남길 수 있습니다. 연결 목록은 원고 자동 저장과 별도로 저장되며, 다른 탭에서 먼저 바뀌면 최신 목록 확인을 요청합니다.

인물 드롭다운에는 해당 회차 시작 시점의 소속과 직위를 함께 표시합니다. 등장 목록은 AI 검색 우선순위로 사용되며, 비어 있다고 해서 다른 모든 항목이 등장하지 않는다는 뜻으로 해석하지 않습니다.

## 집필 참고 패널

상단 `세계관·지도` 버튼으로 원고 옆 참고 패널을 엽니다. 세계관 탭은 지도 배치 목록과 같은 경량 자료를 사용하며 항목에 마우스를 올리거나 키보드 초점을 두면 이미지·카테고리·설명 미리보기를 표시합니다. 미니맵 탭은 기존 지도 이미지와 저장된 핀 좌표를 읽기 전용으로 축소해 보여줍니다. 참고 패널을 열어도 원고 편집기와 현재 커서가 다시 만들어지지 않습니다.

## 지속 상태 메모

캐릭터 또는 작품 전체의 현재 정전을 기록합니다.

- 현재 위치와 시간
- 부상·감정·신분 변화
- 소지품의 획득·사용·분실
- 기술·능력의 습득과 제한
- 관계와 복선 상태

각 기록은 기준 챕터와 대상을 가질 수 있습니다. 집필 에이전트와 일관성 검사가 현재 상태를 검색하므로, 장면이 끝난 뒤 중요한 변화만 갱신하는 습관이 유용합니다.

## 집필 에이전트

집필 지능 패널에서 작성 요청과 목표 글자 수를 지정합니다.

```text
작품 기억·창작 지식 검색
  → 장면 계획
  → 초안 스트리밍
  → 선택적 비평
  → 수정본
  → 작가가 확인 후 현재 커서에 삽입
```

완료 신호를 받지 못한 부분 출력은 원고 삽입이 잠깁니다. 생성 결과는 자동으로 원고를 덮어쓰지 않으며 작가가 **현재 커서에 삽입**을 선택해야 반영됩니다. 웹 검색이 필요한 고증 요청은 검색 모드를 켤 수 있습니다.

## 일관성 검사

전체 일관성 검사는 프로젝트 설정, 캐릭터, 세계관, 상태 메모와 원고에서 충돌 후보를 찾습니다. 결과는 오류·주의·참고, 근거와 수정 제안으로 표시됩니다. LLM 검사는 작가의 정전 판단을 대신하지 않으므로 근거 원문을 확인하세요.

## Ghost Text

커서 위치에 짧은 자동완성을 표시하며 `Tab`, `Alt+→`, `Esc` 등을 지원합니다. 현재는 품질 개선이 진행 중이므로 긴 장면 생성보다 한 문장 수준의 보조 제안으로 사용하세요. 자세한 제한은 [Ghost Text 자동완성](Ghost-Text)에 있습니다.

집필 화면의 `Ghost Text 켜짐/꺼짐` 버튼으로 프로젝트별 브라우저 환경에서 자동완성을 즉시 중단하거나 다시 켤 수 있습니다. 끄면 진행 중 요청과 표시 중 제안도 제거됩니다.

# 주요 기능과 지원 범위

## 프로젝트와 원고

- 소설 프로젝트 생성·수정·삭제
- 챕터 생성·정렬·검색과 Plate.js 리치 텍스트 편집
- 서버 자동 저장과 IndexedDB/localStorage 복구본
- 프로젝트별 시놉시스, 집필 기준, 문체 프로필, 작가 노트
- 큰 목록은 일부만 렌더링하고 더 보기로 확장

자세한 사용법: [집필 작업실](Writing-Workspace)

## 스토리 구상

- 홈에서 AI와 대화하며 제목·장르·시놉시스·인물·세계관·첫 장 개요 구성
- 생성 중 텍스트를 스트리밍으로 표시
- 구조화 초안을 계속 수정하고 최종 승인 시 프로젝트로 일괄 생성
- 구상 중 세션은 브라우저에 임시 저장

자세한 사용법: [스토리 구상](Story-Planning)

## 캐릭터와 세계관

- 캐릭터의 역할·성격·배경·아크·소지품과 관계 관리
- 카테고리 특성 기반 캐릭터 소속·직위, 복수/대표 소속과 회차별 변화 이력
- 세계관 카테고리 생성·이름 변경·삭제
- 세계관 항목과 관련 항목 연결
- World assistant의 내부 지식/웹 검색 → 후보 생성 → 승인·거부 흐름
- 기존 설정의 AI 수정안 비교, 영향 경고, 수정 이력과 복원

자세한 사용법: [세계관 구축](World-Building), [설정 수정·복원](Setting-Revisions)

## 세계관 지도

- 지도 이미지 최적화, 폴더, 이름 변경, 이미지 교체
- 캐릭터·세계관·다른 지도 핀 배치
- 화면 맞춤부터 확대, 팬, 마퀴·다중 선택, 일괄 이동·삭제
- 핀별 색상·활성 상태, 사용자 팔레트, 클러스터
- 원본 항목 상세·수정, 지도 연결 미리보기와 끊어진 링크 복구
- 핀 좌표의 명시적 일괄 저장과 저장본 불러오기

자세한 사용법: [세계관 지도](World-Maps)

## 집필 지능

- 프로젝트 기억 인덱스 동기화와 전체 일관성 검사
- 장면 계획 → 초안 → 선택적 비평·수정 집필 에이전트
- 창작 위키와 작품 기억을 의미 검색 또는 키워드 검색으로 결합
- 위치·상태·소지품·기술·관계·복선을 기록하는 지속 상태 메모
- 회차별 직접 등장/언급 인물·장소·물건·단체 드롭다운과 해당 시점 소속 참조
- 웹 검색 사용 여부를 작업별로 선택

Ghost Text는 자동/수동 호출, 부분 적용과 취소가 구현되어 있지만 품질 고도화가 필요한 미완성 기능입니다. [Ghost Text 문서](Ghost-Text)의 제한을 확인하세요.

## AI와 검색

- OpenAI, Anthropic, Ollama, NVIDIA, KoboldCpp, OpenAI 호환 Local LLM
- 공통 AI 설정과 프로젝트별 덮어쓰기
- 서버측 단일 슬롯 기본 대기열, 취소, 단계별 진행 상태, 10분 장기 요청 제한
- SearXNG 검색 계획·검증·요약·출처 표시
- OpenAI 호환 임베딩 장애 시 키워드 검색 자동 전환

## 이미지와 LoRA

현재 캐릭터 초상화·전신·삽화 프리셋과 Diffusers/Automatic1111 API 호출, 갤러리 저장, LoRA 레지스트리 선택·가중치 전달이 있습니다. LoRA 학습·배포·실제 가중치 적용은 외부 서비스 계약에 따라 달라지며 Muse Novel이 GPU 프로세스를 직접 관리하지 않습니다. 세계관 지형·도시·건물 이미지 생성은 아직 구현 예정입니다.

자세한 범위: [이미지 생성과 LoRA](Image-Generation)

## 보안과 운영

- 단일 관리자 계정, salt+scrypt 비밀번호 해시, 서명 세션 쿠키
- Origin 검증과 로그인 시도 제한
- SQLite 영구 볼륨, 업로드 저장소, `/api/health`, 운영 진단
- 외부 API 장애와 원고 편집 기능의 격리

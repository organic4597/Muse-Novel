# 주요 기능

## 프로젝트 관리

- 홈 화면에서 소설 목록 확인
- 새 소설 수동 생성
- 프로젝트별 설정/문체/AI provider 관리

## 챕터 작성

- Plate.js 기반 리치 텍스트 편집기
- 자동 저장
- 챕터 정렬과 구조 관리

## 등장인물 / 세계관

- 등장인물 정보, 성격, 배경, 아크 정리
- 세계관 항목 생성 및 연결
- 설정 참조용 구조화 문서화

## AI 보조 작성

- 프로젝트 컨텍스트 기반 보조 작성
- 명령형 편집 API
- 프로젝트별 AI 설정 사용

## 스토리 구상 탭

- 홈 화면에서 AI와 대화하며 소설 기획
- 제목 / 장르 / 시놉시스 / 캐릭터 / 세계관 / 1장 개요를 구조화
- 대화 결과를 새 프로젝트로 즉시 적용

## 태그 추천 / 이미지 프롬프트 보조

- 한국어 입력을 영어 태그로 번역
- 임베딩 기반 태그 추천
- 상주 Python 서버로 빠른 반복 호출 지원

## 테마

- 라이트 / 다크 / 시스템 테마 지원

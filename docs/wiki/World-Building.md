# 세계관 구축

프로젝트의 **캐릭터**와 **세계관** 탭에서 작품 설정을 구조화하고, 지도·집필 기억·일관성 검사와 연결합니다.

## 카테고리와 항목

- 기본 카테고리 외에 사용자가 새 카테고리를 추가할 수 있습니다.
- 카테고리 이름을 바꾸면 연결된 항목의 분류도 함께 갱신됩니다.
- 카테고리를 삭제할 때 하위 항목 처리 방식을 확인합니다.
- `물건`, `영약`, `기술`, `사건`처럼 작품에 필요한 분류를 자유롭게 만들 수 있습니다.

항목에는 제목, 설명, 태그, 출처와 관련 항목을 저장합니다. 공청석유 같은 영약은 `물건` 또는 사용자가 만든 `영약` 카테고리에 넣을 수 있습니다.

카테고리에는 항목 태그와 별도로 `단체`, `장소·지형`, `물건` 특성을 지정할 수 있습니다. `단체` 특성 카테고리의 세계관 항목만 캐릭터 소속으로 선택할 수 있고, 나머지 특성은 집필 화면의 회차별 표시 그룹을 결정합니다. 카테고리 이름을 바꿔도 ID 기반 특성은 유지됩니다.

캐릭터 상세의 `소속 · 직위`에서 복수 소속과 대표 소속을 정하고 초기 설정, 회차 시작, 회차 종료 후 변화를 기록합니다. 기록 정정과 삭제는 별도 감사 이력을 남기며, 회차가 삭제되면 기록을 초기 상태로 오인하지 않고 연결 끊김 이력으로 보존합니다.

## World assistant

자연어 요청으로 여러 세계관 항목의 초안을 만들 수 있습니다.

1. 요청의 생성 대상·개수·분류를 해석합니다.
2. 기존 작품 설정과 내부 창작 지식을 확인합니다.
3. 정보가 부족하고 검색이 허용된 경우에만 SearXNG를 조회합니다.
4. 생성할 개별 항목 명단을 추출하고 기존·대기 항목과 중복을 검사합니다.
5. 작은 묶음으로 설명을 생성하고 누락된 항목을 보완합니다.
6. 검토 후보에 요청 수량·생성 수량·누락과 출처를 표시합니다.
7. 작가가 승인한 후보만 실제 세계관에 저장합니다.

요청 분석은 새 항목 생성, 기존 항목 수정, 두 작업이 섞인 요청을 의미 기준으로 구분합니다. 기존 항목 수정 요청은 중복으로 건너뛰지 않고 변경 전·후가 있는 별도 수정 후보로 표시합니다. **수정 승인**을 눌러야 실제 항목에 반영되며, 승인 전 내용은 수정 이력에 저장됩니다. 검토 중 다른 화면에서 항목이 바뀌면 버전 충돌을 알리고 덮어쓰지 않습니다. 현재 화면을 새로고침하면 승인하지 않은 기존 항목 수정 후보는 사라지므로 다시 생성해야 합니다.

후보는 새로고침 후에도 남지만 승인 전에는 집필 컨텍스트와 정전 검색에서 제외됩니다. 승인과 거부에는 LLM을 다시 호출하지 않습니다.

후보 설명은 현재 작품 세계 안에서 대상이 어떤 존재인지 설명하는 설정집 문장으로 작성합니다. 특정 단어를 금지하거나 정규식으로 서술 관점을 판정하지 않습니다. 같은 단어도 세계 내부의 서점·공연·문화 등을 설명하는 데 자연스럽게 쓰일 수 있기 때문입니다.

초안 생성 뒤에는 요청·작품 설정·설명 전체를 묶어 LLM이 서술 관점을 검토합니다. 보완이 필요하면 원문에서 근거 구절과 수정 이유를 받아 해당 항목만 한 차례 다시 작성하고 재검토합니다. 단일 항목 제안에도 같은 검토를 적용합니다. 검토 결과의 항목명·개수·인용 일치 여부는 서버가 검사하며, 최종 승인·거부는 작가가 결정합니다.

검토는 일괄 생성 시 최대 4개를 한 번에 처리하므로 정상 생성에도 묶음당 추론 호출 한 번이 추가됩니다. 기존 요청 제한 시간 안에서 동작하고 재검토도 실패하면 미완료로 안내합니다. LLM의 관점 판정은 완벽하지 않으며, 이 검토만으로 사실 정확성이나 설정 일관성이 보장되는 것은 아닙니다.

## 검색 사용 기준

- **필요할 때 자동**: 모델이 고증·최신 정보·낯선 용어에 검색이 필요한지 판단
- **항상 검색**: 공개 자료 확인이 반드시 필요한 요청
- **끄기**: 순수 창작 또는 외부 검색을 원하지 않는 요청

검색 결과는 문서 전체를 자동 수집한 것이 아니라 검색엔진 요약입니다. 커뮤니티 자료와 창작 제안은 사실 자료와 구분해 검토하세요. 자세한 흐름은 [AI 웹 조사](Web-Research)에 있습니다.

## 관련 항목과 설정 수정

캐릭터 관계와 세계관 링크로 항목 간 연결을 만들 수 있습니다. 기존 설정을 AI로 수정할 때는 수정안을 먼저 비교하고, 영향 가능성을 경고한 뒤 승인한 필드만 저장합니다. 이전 값은 이력으로 남아 복원할 수 있습니다. [설정 수정·복원](Setting-Revisions)을 참고하세요.

## 지도 연결

승인된 캐릭터·세계관 항목은 지도 탭의 배치 목록에 나타납니다. 지도 화면 우측 하단 World assistant 리모콘을 클릭해도 같은 후보 생성·승인 흐름을 사용할 수 있으며, 승인한 항목은 배치 목록에 즉시 추가됩니다.

# Muse Editorial Design System

Muse Novel의 UI는 **작가의 서재와 편집실**을 하나의 작업 공간으로
표현합니다. 장식보다 원고와 정보 위계를 우선하고, 모든 화면에서 같은
색상·타이포그래피·간격·상호작용 규칙을 사용합니다.

## 시각 방향

- 라이트 테마: 따뜻한 종이색 배경, 짙은 잉크색 본문
- 다크 테마: 푸른 검정보다 자주색이 아주 약하게 섞인 잉크 배경
- 브랜드 포인트: 라이트에서는 짙은 자주색, 다크에서는 황동색
- 제목과 원고: 한국어 세리프, 조작 UI와 보조 정보: 산세리프
- 표면은 큰 모서리와 얇은 테두리를 사용하며 그림자는 낮고 넓게 처리

## 의미 기반 토큰

색상은 `src/app/globals.css`의 shadcn/Tailwind 의미 토큰을 통해 사용합니다.
컴포넌트에서 고정 HEX 색상을 새로 만들지 않고 다음 토큰을 우선합니다.

- `background` / `foreground`: 전체 작업 공간과 기본 글자
- `card` / `card-foreground`: 원고, 패널, 대화 표면
- `primary`: 핵심 행동과 현재 위치
- `accent`: hover, 선택 전 보조 강조
- `muted` / `muted-foreground`: 메타데이터와 비활성 정보
- `brand` / `highlight`: 장식용 그라데이션과 선택 영역

## 공통 컴포넌트

- `.muse-panel`: 페이지의 주요 작업 단위
- `.muse-card`: 클릭 가능한 작품·인물·세계관 카드
- `.muse-empty`: 비어 있는 목록의 안내 영역
- `.muse-eyebrow`: 영문 작업 영역 라벨
- `.muse-display`: 페이지 대표 제목
- `.muse-field-label`: 입력 필드 라벨

버튼, 입력창, 탭, 다이얼로그는 공통 UI 컴포넌트를 사용합니다. 페이지에서
각각 별도의 radius, shadow, focus ring을 만들지 않습니다.

## 레이아웃

- 전체 최대 폭: `92rem`
- 콘텐츠 좌우 여백: 모바일 `1rem`, 태블릿 `1.5rem`, 데스크톱 `2rem`
- 집필 화면: 17rem 목차 + 유동 원고 영역
- 원고 본문 실제 읽기 폭: 약 720px
- 긴 설정 화면은 섹션 사이에 충분한 수직 간격을 두고 관련 설정만 패널로 묶음

## 상호작용과 접근성

- 모든 동작은 색상 외에 아이콘, 텍스트 또는 위치 변화로 상태를 구분
- 포커스 링을 제거하지 않으며 `ring` 토큰으로 통일
- hover 이동은 2px 이내로 제한해 화면이 흔들리지 않도록 함
- 모바일에서 핵심 버튼과 탭의 최소 높이는 44px에 가깝게 유지
- 원고 작성 중에는 장식보다 텍스트 대비와 행간을 우선
- 긴 상세 팝업은 내용량과 화면 크기에 맞춰 폭·높이를 조절하고 내부 스크롤을 제공
- 지도처럼 좌우 도구가 필요한 화면은 중앙 작업 영역을 침범하지 않는 범위에서 보조 패널 폭을 확보
- hover는 미리보기 용도로만 사용하고 입력 폼·장시간 작업은 명시적 클릭으로 열고 닫음

## 피해야 할 패턴

- 기능 이름 앞에 의미 없는 이모지 사용
- 페이지마다 다른 회색 카드와 radius를 임의로 추가
- 본문 전체를 고채도 브랜드색으로 표시
- 한 화면에 동일한 무게의 CTA를 여러 개 배치
- 원고 읽기 폭을 화면 전체로 확장

## 참고

OpenDesign의 디자인 시스템 패키지 원칙처럼 디자인 규칙과 토큰을 코드의
공통 계약으로 관리합니다. Novel의 집중형 WYSIWYG 편집 경험과 Grain의
미니멀한 장문 집필 방향도 참고했지만, Muse Novel의 정보 구조와 한국어
가독성에 맞게 별도로 구성했습니다.

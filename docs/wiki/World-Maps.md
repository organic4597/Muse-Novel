# 세계관 지도

프로젝트의 **지도** 탭에서 PNG/JPG/WebP 이미지를 등록하고 캐릭터·세계관 항목과 다른 지도를
정규화 좌표 핀으로 배치합니다. Muse Novel 서버가 이미지를 표시용(최대 2048px), 고해상도용
(최대 4096px), 썸네일(최대 480px) WebP로 한 번 재처리합니다. 파일은 기존 영구 업로드 경로의
`maps/`에 저장됩니다. 최대 12MB, 3,200만 화소의 정적 이미지 한 장만 처리합니다.

## 지도와 폴더

- 좌측 목록의 지도 폴더는 생성·이름 변경·삭제할 수 있습니다.
- `미분류`는 DB 행이 아닌 기본 그룹이며 이름 변경·삭제할 수 없습니다.
- 폴더를 삭제하면 FK `SET NULL`로 하위 지도만 미분류에 이동합니다.
- 지도는 좌측 목록에서 폴더나 미분류로 드래그해 이동합니다. 현재 지도의 폴더 선택 메뉴는 모바일·키보드 대안으로 유지하며, 이름 변경·삭제·이미지 교체도 가능합니다.
- 비율이 다른 이미지로 교체할 때는 좌표가 달라 보일 수 있음을 확인한 뒤 진행합니다.
- 지도 삭제 시 그 지도의 핀과 이미지 3종은 삭제됩니다. 다른 지도가 연결한 지형 핀은 남고 연결만 끊깁니다.

## 핀 편집

항목을 드래그해 지도에 놓거나, 항목/지도를 선택한 뒤 지도 위치를 클릭합니다. 같은 항목을 한
지도나 여러 지도에 반복 배치할 수 있습니다. 좌클릭 빈 공간 드래그는 마퀴 선택, 우클릭 드래그는
팬, 휠은 커서 기준 줌입니다. 최소 배율은 지도 전체가 보이는 화면 맞춤 100%이며 그보다 작게
축소할 수 없습니다. 선택된 여러 핀은 상대 위치를 유지하며 이동하거나 함께 삭제합니다.

지도 화면 우측 하단의 **World assistant** 리모콘을 클릭하면 세계관 탭과 같은 검색·후보
승인/거부 흐름을 사용할 수 있습니다. 승인한 항목만 확정 세계관과 지도 배치 목록에 즉시 추가됩니다.

추가·이동·삭제·활성 상태·지형 링크 변경은 모두 브라우저 초안입니다. 상단 **저장**을 눌러야
전체 핀 스냅샷을 하나의 SQLite 트랜잭션으로 반영합니다. 지도당 최대 500개이며 좌표는 이미지 대비
0~1 범위입니다. 버전이 달라졌으면 초안을 유지한 채 충돌을 알립니다. 페이지 이동과 새로고침 전에는
저장하지 않은 변경을 경고합니다.

지도 목록에서 다른 지도를 열면 그 지도에 저장된 좌표와 상태를 자동으로 불러오며 개수를 안내합니다.
현재 지도의 서버 저장본으로 돌아가려면 **저장된 핀 위치 불러오기**를 누릅니다. 저장하지 않은 초안이
있으면 버리기 전에 확인합니다. 이미지 교체도 같은 지도 ID를 유지하므로 정규화 좌표를 그대로 불러옵니다.

핀은 60% 투명도의 얇은 바늘 형태이며, 우측 상세의 색상 선택기로 각 핀 머리색을 따로 지정할 수
있습니다. 자동 색상으로 되돌릴 수도 있습니다. 비활성 핀은 지정색을 보존하면서 회색으로 표시됩니다.
개별 핀 hover에는 해당 항목의 요약만 표시하며 주변 핀 목록을 붙이지 않습니다. 여러 항목 선택 목록은
화면에 실제 클러스터 개수 배지가 표시된 경우에만 제공합니다. 화면 좌표 격자로 인접 핀을 묶기 때문에
확대할수록 클러스터가 풀립니다. 클러스터와 축약 라벨의 팝업 목록에서 개별 핀을 선택할 수 있습니다.

## 상세 정보와 지형 핀

일반 핀 hover에는 대표 이미지·종류·요약을 표시하고, 클릭하면 우측 패널이 원본 항목의 기본 정보,
태그, 출처, 관련 항목을 지연 조회합니다. 이 화면에서 핀 활성 상태만 바꾸며 원본 항목 자체는 수정하지
않는 것이 기본입니다. **원본 항목 수정**을 누르면 기존 캐릭터/세계관 수정 폼을 팝업으로 열어
내용을 수정할 수 있습니다. 저장 이력도 기존 수정 경로대로 남고, 변경된 이름·분류·요약은 같은
항목을 가리키는 지도 핀에 즉시 반영됩니다. 원본 캐릭터/세계관 항목 삭제는 FK `CASCADE`로 관련 핀을 즉시 제거합니다.

지형 핀은 다른 지도에 연결합니다. hover 미리보기는 대상 지도의 썸네일 위에 저장된 핀을 SVG로
합성합니다. 미리보기를 누르면 대상 지도로 이동합니다. 자기 지도 연결은 차단합니다. 순환 링크는
허용하되 선택 시와 저장 시 경고합니다. 대상 지도가 삭제된 핀은 `linked_map_id = null`로 남으며,
우측의 복구 선택창에서 다른 지도에 다시 연결할 수 있습니다.

## 구현 선택

추가 지도 라이브러리 없이 기존 React, SVG, Pointer Events, ResizeObserver, Radix HoverCard와 SQLite를
재사용합니다. 포인터 이동은 `requestAnimationFrame`으로 묶고 화면 밖 마커는 렌더링하지 않습니다.
500핀 상한을 넘겨야 하거나 타일 지도가 필요해질 때만 공간 인덱스/타일 엔진 도입을 검토합니다.

참고: [Leaflet의 이미지 좌표 지도](https://leafletjs.com/examples/crs-simple/crs-simple.html),
[Konva의 커서 기준 확대 방식](https://konvajs.org/docs/sandbox/Zooming_Relative_To_Pointer.html),
[Sharp 리사이즈 API](https://sharp.pixelplumbing.com/api-resize/).

# 작가 노트 작업 공간 구현 계획

기준일: 2026-09-08

## 목표

원고 목차 아래에 프로젝트별 `작가 노트` 폴더를 제공하고, 작가가 전체 플롯·장면 아이디어·설정 초안·참고 이미지를 넓은 중앙 공간에서 정리할 수 있게 한다.

## 구조

- 좌측 사이드바: 작가 노트 루트, 사용자 폴더, 텍스트 노트와 마인드맵 노트
- 텍스트 노트: 제목과 자유 형식 구상 메모를 자동 저장
- 마인드맵: 텍스트 카드와 이미지 카드를 자유 배치하고 카드 사이를 연결
- 중앙 작업 공간: 노트를 선택하면 원고 대신 전체 폭을 사용하고, 챕터를 누르면 원래 집필 화면으로 복귀
- 저장: 프로젝트별 SQLite 데이터와 기존 영구 업로드 볼륨 사용

## 구현 단계

1. 노트 폴더·노트·이미지 자산 스키마와 CRUD API
2. 좌측 폴더 트리와 텍스트 노트 작업 공간
3. 드래그 카드·연결선·이미지 업로드가 가능한 마인드맵
4. 회귀 테스트, 프로덕션 빌드, 운영 서버 배포

## 현재 구현 상태

- 완료: 프로젝트별 폴더·텍스트 노트·마인드맵·이미지 자산 API
- 완료: 좌측 작가 노트 폴더 트리와 노트 생성·이름 변경·삭제
- 완료: 중앙 전체 폭 텍스트 구상 공간과 자동 저장
- 완료: 자유 배치 카드, 카드 연결선, 이미지 카드가 있는 마인드맵

## 안전 조건

- 노트와 이미지 자산은 프로젝트 소유권을 매 요청 확인한다.
- 이미지 파일은 크기·형식·화소 수를 제한하고 WebP로 정규화한다.
- 노트 삭제 시 해당 노트 전용 이미지만 제거한다.
- 다른 사용자나 프로젝트의 노트·자산 경로를 재사용할 수 없다.

# 원고 비평가와 모바일 Ghost Text 계획

기준일: 2026-09-08

## 원고 비평가

- 현재 챕터의 원고와 작품 설정·활성 문체를 함께 검토한다.
- 기본 강도는 `적극적 리라이트`이며 필요하면 `균형 편집`으로 낮출 수 있다.
- 맞춤법보다 장면 초점·긴장·감정 인과·설명 밀도·이미지·속도·대사 서브텍스트·인물 목소리를 우선한다.
- 연속된 1~4문장을 문장 또는 문단 단위로 병합·분할·재배열한 리라이트를 최대 12건 제안한다.
- 직접 교체하기 어려운 장면 전체 문제는 별도 장면 메모와 편집 방향으로 표시한다.
- 응답은 효과가 큰 리라이트 최대 4건과 장면 메모 최대 3건으로 제한해 60초 무응답을 피한다.
- 일부 AI 항목의 분류나 길이가 잘못되어도 유효한 나머지 항목은 독립적으로 복구한다.
- 로컬 llama.cpp에는 JSON Schema 응답 형식을 강제해 원고의 따옴표와 줄바꿈 때문에 결과 파싱이 깨지지 않게 한다.
- AI가 인용한 원문이 실제 원고에 정확히 한 번 존재해야 표시한다. 적극 모드는 확신도 55%, 균형 모드는 65% 이상을 사용한다.
- 현재 문장, 개선 문장, 근거를 비교한 뒤 사용자가 `승인하고 교체`를 눌러야 원고를 변경한다.
- 승인 시 정확한 원문 범위만 교체하며 기존 자동 저장과 실행 취소 기록을 사용한다.
- 문장·문단 제안이 여러 Plate 텍스트 노드와 문단 경계를 지나도 원고와 같은 줄바꿈 기준으로 범위를 찾아 교체한다.
- 불필요한 구간은 빈 리라이트를 승인해 삭제할 수 있다.
- 긴 챕터는 우선 최근 20,000자를 검토하고 범위를 화면에 명시한다.

## 모바일 Ghost Text

- 작은 화면에서 Ghost Text를 숨기던 CSS 제한을 제거한다.
- 키보드 단축키 대신 `적용`, `다시`, `닫기` 버튼을 인라인으로 제공한다.
- 연속 입력 중에는 요청하지 않고 기존 350ms debounce와 2초 자동 요청 cooldown을 동일하게 적용한다.

## 후속 개선

- 비평 범위를 선택 영역·현재 장면·전체 챕터로 선택
- 여러 제안을 한 번에 승인하기 전 충돌 미리보기
- 비평 결과 버전 보관과 일괄 되돌리기
- 모바일 후보 앞·뒤 전환과 화면 하단 고정 조작 막대
